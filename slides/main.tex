\begin{frame}{The problem}
\begin{columns}[T]
\column{0.55\textwidth}
\begin{itemize}
\item Two far-apart nodes want shared entangled pairs (Bell pairs).
\item Each link makes pairs by trying $M$ times per round. Each try works with chance $q$.
\item Middle nodes join pairs by \emph{entanglement swapping}. Every join lowers fidelity, so a path may have at most 4 middle nodes.
\item Pairs are thrown away at the end of each round.
\end{itemize}
\column{0.42\textwidth}
\kid{every road throws paper planes across a river each round. The ones that land are that road's seats. A middle city glues two pairs into one longer pair, but each glue adds a little grey paint.}
\end{columns}
\end{frame}

\begin{frame}{The paper's claim}
\begin{itemize}
\item A request needs $n$ pairs between two nodes before its deadline.
\item \textbf{Single path:} all $n$ pairs over one route.
\item \textbf{Multipath:} the pairs split over routes that share no link.
\item The paper solves each round with an exact ILP and with a fast greedy heuristic.
\item Headline: multipath turns away fewer requests. At $q=0.9$: blocking ratio \paperBRMPILPqNine{} (multipath) against \paperBRSPILPqNine{} (single path).
\end{itemize}
\vspace{0.6em}
\kid{send your postcards on several mail routes instead of one, so a single busy road cannot stop you.}
\end{frame}

\begin{frame}{What the paper left out, and how we handled it}
\begin{itemize}
\item The pair demand $n$, the number of paths $K$, the fidelity model and more are not given.
\item We recorded 27 explicit assumptions (\texttt{ASSUMPTIONS.md}). Each one is cited where the code uses it.
\item $n$ was calibrated on one quantity only: how often the heuristic splits ($\Gamma$, the paper's Table~I).
\item The blocking ratio was never used for tuning, so it is a fair, held-out test.
\item We also found 7 inconsistencies in the paper, for example an $\alpha$ value printed as 4/2 that should be 3/2.
\end{itemize}
\end{frame}

\begin{frame}{How we know the code is right}
\begin{itemize}
\item Two toy networks solved \textbf{by hand}, committed before any solver code existed.
\item The paper's own Fig.~1 example, reproduced path for path.
\item The ILP checked against brute force and against a second formulation (200 random windows).
\item In every one of \auditWindows{} audited windows, heuristic $\le$ capped ILP $\le$ ILP, with \auditViolations{} violations.
\item Planted bugs that the tests must catch, and do.
\item Same dice for everyone: for a given seed, every method sees the same requests and link outcomes.
\end{itemize}
\end{frame}

\begin{frame}{Part A: what did not reproduce}
\begin{columns}[T]
\column{0.5\textwidth}
\begin{itemize}
\item \textbf{Levels.} At $q=0.9$ our ILPs block \brMPILPqNine{} and \brSPILPqNine, against the paper's \paperBRMPILPqNine{} and \paperBRSPILPqNine.
\item \textbf{Heuristic against ILP.} The paper calls them comparable. Ours: \brMPHeuqFive{} against \brMPILPqFive{} at $q=0.5$.
\item \textbf{Why the gap:} greedy search alone (\brMPHeuDoneqFive) and the spare-seat rule alone (\brMPILPDeltaqFive) cost little. Together they cost a lot.
\end{itemize}

\end{columns}
\end{frame}

\begin{frame}{Why are our blocking levels lower?}
\begin{columns}[T]
\column{0.48\textwidth}
\begin{itemize}
\item Two readings of the request model are open: arrival \emph{gaps} instead of arrival times, and $n$ pairs \emph{per slot} instead of per round.
\item We tested both after Part A was frozen, with the same \sensSeeds{} seeds.
\item \textbf{Per slot} lands near the paper's levels. \textbf{Gaps} does not: it blocks requests that never arrive in time.
\item Multipath is never worse under any reading.
\end{itemize}
\column{0.5\textwidth}

\end{frame}

\begin{frame}{Part B: the same question in QuNetSim}
\begin{itemize}
\item Real swaps: \texttt{send\_epr}, Bell measurement, two classical bits, Pauli fix. All \pbCorrelated{} pairs correlated.
\item $M$ attempts per link per round, chance $q$, shared by all requests (A22). 20 seeds.
\item (a, b) Multipath wins when capacity is short. (c) Under packet drop it does not: its second path can be longer.
\end{itemize}

\begin{frame}{Extension: keep a spare seat, except on your last chance}
\begin{columns}[T]
\column{0.49\textwidth}
\begin{itemize}
\item Hypothesis fixed before any run: at $q=0.5$, blocking drops by at least \extThreshold.
\item Result: a drop of \extDiffqFive{} (CI \extCIloqFive{} to \extCIhiqFive). \textbf{Supported.}
\end{itemize}
\column{0.49\textwidth}
\begin{itemize}
\item But no spare seat for anyone ($\delta=1$) gives a drop of \extDoneDiffqFive.
\item So the rule itself is the cost, not the deadline.
\end{itemize}
\end{columns}

\begin{frame}{Limitations}
\begin{itemize}
\item The abstract model is a simplification: perfect swaps, no memory decay, fidelity only as a hop limit.
\item QuNetSim is a qualitative check, not real hardware: no noise, and link failure comes from our own budget.
\item The results depend on the parameters we chose: $n$, $K$ and the arrival model are not in the paper.
\item The fidelity model is inferred. It reproduces both of the paper's hop limits.
\end{itemize}
\end{frame}

\begin{frame}{Takeaways}
\begin{itemize}
\item \textbf{Reproduced:} multipath blocks fewer requests than single path, at every $q$ and every load, for both the heuristic and the ILP.
\item \textbf{Not reproduced:} the paper's blocking levels and its heuristic-ILP closeness. Both depend on details the paper leaves out.
\item \textbf{Extension:} the heuristic's spare-seat rule causes most of its gap to the ILP.
\item Everything reruns from the repository with three commands.
\end{itemize}
